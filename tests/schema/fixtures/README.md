# Claim-contract fixtures

`module_inapplicable.json` and `support_with_unresolved.json` are unchanged copies of the two public evidence
fixtures in the September 12, 2026 independent review. They use the record format of versions up to 0.1.5 and remain
valid legacy input. The adjudicator distinguishes a gate that does not apply from an out-of-scope claim, and a legacy
`"unresolved"` consequence on a required property leaves that property open. The test exporter executes these
inputs against the explicitly identified package implementation.
